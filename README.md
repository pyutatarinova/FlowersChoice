# Инструкция по запуску проекта
1) Необходимо проверить, что в корне проекта лежит .env файл с следующими кредами(представлен шаблон):
```yaml
DB_USER=postgres
DB_PASS=postgres  
DB_NAME=flowersdb
DB_PORT=5001
```
2) Далее находясь в корне проекта необходимо запустить команду:
```yaml
    docker compose up
```
